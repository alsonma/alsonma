## 01. About Me

I'm an aspiring software engineer focused on building reliable, maintainable, and scalable applications through strong engineering fundamentals, full-stack development, and continuous learning.

My approach combines practical implementation with an understanding of how software systems are designed, developed, secured, tested, and deployed. I enjoy translating ideas into functional products, solving technical problems, and improving code quality through structured thinking.

- **Software Engineering:** Writing clean, modular, maintainable code and understanding core engineering principles.
- **Full Stack Development:** Building end-to-end web applications using JavaScript, React, Node.js, Express.js, and MongoDB.
- **Backend Engineering:** Designing RESTful APIs, implementing CRUD operations, structuring applications with MVC, and managing data persistence.
- **AI / ML Exploration:** Developing foundational knowledge of artificial intelligence, machine learning, data processing, and intelligent application development.
- **Product Engineering:** Thinking beyond individual features to consider usability, performance, reliability, security, and long-term maintainability.
- **Deployment & Tooling:** Working with Git, GitHub, development environments, and modern application deployment workflows.

**Engineering philosophy:** Understand the problem. Design the solution. Build with purpose. Test thoroughly. Improve continuously.

**Open To:**
- Software Engineering and Full Stack Development opportunities.
- Junior Backend and MERN Stack Developer roles.
- Collaborative open-source projects.
- Practical AI / ML projects and engineering-focused learning.
- Internships, technical mentorship, and challenging development opportunities.
